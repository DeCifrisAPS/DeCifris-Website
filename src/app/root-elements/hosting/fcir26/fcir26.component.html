October 6th, 2026
Centro Convegni "Carlo A. Ciampi", Via Nazionale 190, Rome (Italy)

Organizing Committee

Chairs: Michela Iezzi (Banca d'Italia) and Massimiliano Sala (University of Trento).

Invited Speaker

Ludovic Perret (EPITA, Sorbonne University)
Post-Quantum Migration in the Financial Sector

Description

Financial Cryptography in Rome returns in 2026, following the 2025 edition. The program covers post-quantum cryptography in the financial sector, blockchain risks, stablecoins, verifiable money, and encryption for privacy-preserving applications.

For more information, contact fcir26@decifris.it.
